03 — Build It

How to Build the GTM Agent

Three steps. You need OpenClaw running, a Claude API key, and about 30 minutes.

1

Create the OpenClaw Workflow

In your OpenClaw workspace, create a new folder called gtm-agent. Inside it, create the following files. This is the skeleton of your agent.

# file: gtm-agent/PROMPT.md

You are a senior GTM strategist with 10 years of experience in product marketing,
growth, and competitive analysis. Your job is to take a product idea or URL and
produce a complete, actionable go-to-market research package.

Always follow this output structure:
1. Market Snapshot (2–3 sentences, current state)
2. Top 3 Competitors (table: Name | Positioning | Price | Key Message)
3. Top 5 Customer Pain Points (from reviews, Reddit, G2)
4. Positioning Angles (5 options, each with: angle name, headline, 1-sentence description)
5. ICP Definition (demographics, psychographics, top objection, where to find them)
6. Cold Outreach Template (1 email + 1 LinkedIn DM)
7. 30-Day GTM Checklist (top 10 actions)

Be specific. No generic advice. Ground everything in the data you find.

Save this as PROMPT.md — it defines how the agent thinks and what it always outputs.

2

Create the Input Template

Create a simple JSON input file that feeds the agent its context. Replace the values with your specific product.

# file: gtm-agent/input.json

{
  "product": "AI-powered contract review tool",
  "product_url": "https://www.lawGeex.com",
  "target_market": "US-based solo lawyers and small law firms (2–10 people)",
  "price_range": "$49–$199/month",
  "main_channel": "LinkedIn + cold email",
  "your_name": "Alex",
  "your_business": "Legal tech SaaS"
}

Change these values depending on what you're researching. The agent reads this and adjusts all output accordingly.

3

Wire the Agent Together

Create a runner script that reads the input, calls the LLM with your prompt, and outputs the results.

# file: gtm-agent/run.ts

import { readFileSync } from 'fs';
import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic();
const input = JSON.parse(readFileSync('./input.json', 'utf-8'));

const prompt = readFileSync('./PROMPT.md', 'utf-8');

const message = await client.messages.create({
  model: 'claude-opus-4-5',
  max_tokens: 4096,
  system: prompt,
  messages: [
    {
      role: 'user',
      content: `Research and build a GTM package for:
Product: ${input.product}
Market: ${input.target_market}
Price: ${input.price_range}
Channel: ${input.main_channel}`
    }
  ]
});

console.log(message.content[0].text);

// Save output to file
import { writeFileSync } from 'fs';
writeFileSync('./output.md', message.content[0].text);
console.log('✅ GTM package saved to output.md');

Run it with: npx tsx run.ts. Your complete GTM package drops into output.md.

04 — The Critical Prompts

The Prompts That Make
This Actually Work

The difference between a good GTM agent and a useless one is in the prompt. Here are the two most important ones.

🔬 Market Research Prompt Core Prompt
Find and summarize the current market for [PRODUCT CATEGORY]. I need: - Market size (TAM/SAM/SOM) with sources - Top 3 trends shaping this market in 2025–2026 - Who the typical buyer is and their #1 frustration right now - Estimated price range customers are willing to pay - Any regulatory or technical barriers to entry Return a structured paragraph for each point. Be specific, not generic.
📣 Positioning Prompt Core Prompt
Based on the following competitor research: [PASTE COMPETITOR DATA] Generate exactly 5 positioning angles for my product: [YOUR PRODUCT] For each angle include: - Angle name (e.g. "The Speed Play") - One sentence explaining the logic - A 6-word headline - 1-sentence value proposition for a cold email Then pick the strongest angle and write a full cold email template (under 100 words) and a LinkedIn DM (under 50 words) using it.
📋 ICP Prompt Bonus Prompt
Build a detailed Ideal Customer Profile for [PRODUCT]. I need: - Demographics: title(s), company size, geography, tech stack they already use - Psychographics: biggest fear, what they value most, how they make decisions - Top 3 objections they raise before buying - Where to find them online (specific subreddits, LinkedIn groups, podcasts, newsletters) - What "success" looks like for them after using the product Format this as a readable one-pager I could hand to a sales rep.
05 — Stack

Tools You Need

Everything here is free or has a generous free tier. No expensive SaaS required.

OpenClaw Required

Your agent runtime. Install via npm. Runs TypeScript scripts, manages API keys, and orchestrates the workflow.

Claude API Required

$5 free credit on signup. Opus 4.5 gives the best reasoning. Use Haiku for simple tasks to save cost.

TypeScript / Node.js

Everything runs on Node.js. If you can write JavaScript, you can write this. No advanced TS knowledge needed.

Notion Optional

Export your output.md into a Notion page for a clean client-facing GTM document. Agent can auto-create via API.

Perplexity API Optional

For real-time market research. Feed it into Claude for synthesis. Better than browsing manually. ~$5/1000 queries.

GHL / Make.com Optional

For automating outreach once you have the output. Send the cold emails and DMs automatically from the GTM package.
